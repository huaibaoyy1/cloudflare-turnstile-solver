# Five-stage reference index

Use `SKILL.md` for routing and status rules. Load only the stage needed for the current task.

- Stage 1: interpreter, data flow, protocol, state, host bindings, completion, calls, and entry state.
- Stage 2: opcode adaptation, AST containers/naming, result/reference preservation, scopes/virtual functions, completion protocols, execution state, and bounded static acceptance.
- Stage 3: control-flow encodings, loops/transfers, explicit exception regions, adaptation tasks, structure construction, branch state/continuation, and unified reporting.
- Stage 4: function supplementation, legal entry points, isolated bodies, recovery/commit, increment targets, and stopping rules.
- Stage 5: static review, controlled execution/test cases, observable differences, regression, artifact rebuild, and responsibility handoff.

The five stages are not interchangeable completion labels. A static conclusion, an implementation/build result, a runtime result, and a business validation result must remain separate.

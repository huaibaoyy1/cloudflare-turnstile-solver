# Stage 5 decision tree

S5-0. Freeze baseline, final artifact, configuration, and fixture corpus.
S5-1a. Run six static reviews: protocol, state/capture, control flow, functions, exception/cleanup, host boundary.
S5-2. Define independent environments, inputs, controlled dependencies, and effect authorization.
S5-3. Run ordinary entry, initialization, function, stateful-sequence, and targeted-risk cases.
S5-4. Compare values, identities, completion, errors, cleanup, VM/opcode/payload metadata, and request construction.
S5-5. Rebuild responsible artifacts after fixes and rerun affected evidence.
S5-6. Record coverage, differences, and residual unknowns.
S5-7. Assign artifact ownership and handoff.
S5-8. Stop with explicit limitations; finite cases do not establish whole-program equivalence.
